## Interfaces

`esp_shazam_mp3::Encoder` owns one fixed-format encoder. `new()` supports host
tests. Unsafe `with_allocator(Allocator)` accepts lifetime-valid, Send-safe
allocation/deallocation callbacks plus context. `encode(&mut self, &mut
[i16; 2304], &mut [u8; 960])` returns an error on failure; drop releases memory.
Firmware supplies PSRAM callbacks and resets by creating a fresh instance.

`Format::COMPRESSED` selects FLAC or MP3 by the forwarded `mp3-stream` feature;
`path()` and `content_type()` drive all output metadata. `Route::Buffered`
selects the active compressed codec. `BufferPreset::frames(block_samples)`
computes ceil(48,000 * seconds / block_samples). Adapter constants select stack,
block bytes, history and timing without introducing runtime codec state.

## Decisions

Compile-time selection keeps this prototype reversible and avoids designing
runtime switching before the real pipeline is measured. The user already
approved starting; skill approval gates do not require asking again.

## Hardware outcome and next step

The opt-in pipeline is implemented and independently reviewed. Canonical
`scripts/check` passed all 22 stages; both codec profiles build and pass host
checks. Bounded hardware acceptance was executed, with release gates still red.
See [live evidence](../../audit-evidence/2026-10-09/mp3-stream.md).

Boxed PCM fixes a controlled main-task stack overflow. An 8 KiB encoder stack
leaves 5,924 bytes free in measured runs and avoids the observed TLS allocation
failure. Bounded raw-publication retries and MP3 priority 8 keep the encoder
advancing under noise and two listeners. These changes do not fix delivery:
High Sonos and sustained two-listener tests still overrun the encoded history.

Single-listener 60-second decoding, slow-listener isolation/slot reclamation,
and fresh streams after a real Wi-Fi disconnect passed. Medium Sonos played and
kept its queue unchanged after a setting edit. Exact preset offsets have host
coverage; the hardware overlap oracle cannot separate cursor admission skew
from preset error, so it did not pass. Retain that failed result.

Next: correlate sender/AP/receiver delivery before a longer acceptance run;
repair preset measurement with actual cursor-admission evidence. Keep Kata
`e8hd` open and FLAC as default. Do not repeat tuning without a measured cause.
The board must end on the saved production image, stopped, autoplay off, Medium.

Final default-FLAC regression passed the canonical 30-second two-listener soak:
1,440,000 decoded sample frames per channel each, no reported discontinuities.
The final runner verified production restoration and the original stopped
configuration. Hardware failures above remain open; this phase is a local
experimental implementation, not release approval.
